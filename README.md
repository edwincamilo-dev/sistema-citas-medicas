# Sistema de Gestión de Citas Médicas

Software de citas Médicas que mueve el agendamiento a un sistema que trabaja, aunque tú no estes:
el paciente reserva solo, el recordatorio sale automático y la cita queda conectada con la historia clínica y con la factura.

## 🚧 Estado
🟡 **En desarrollo** — Actualmente implementando la capa de persistencia mediante JPA/Hibernate (mapeo de entidades y relaciones de la base de datos).

## 🛠️ Tecnologías
* **Java** (Versión 17 o superior)
* **Spring Boot** (Spring Data JPA / Hibernate)
* **MySQL** (Base de datos relacional)
* **Maven** (Gestor de dependencias)
